        Implemented the numerical evaluation of the double infinite series using \textbf{CUDA C++}, optimizing performance by parallelizing the summation loops on the GPU to handle high-resolution spatial grids. 
        The project features a fully automated pipeline that orchestrates the C++ backend, \textbf{Python (Matplotlib)} for 3D surface plotting, and \textbf{FFmpeg} for video rendering using a custom \textbf{Makefile}.
